# sources

Bibliography and source-note materials live here.

Use `bibliography.md` for source inventory and `source-notes/` for factual notes tied to routing claims. Gameplay research should cite current sources according to the project standards.

Workflow:

1. Add the source to `bibliography.md`.
2. Create a focused source note in `source-notes/`.
3. Link that source note from objective rows, constraint tables, route prototypes, or final guide text.

Do not put uncited gameplay facts directly into route or data files.
