# Source Note: Base-Game Side and Miscellaneous Leftovers Review

Status: needs review.

Source note ID: SN-000026

## Claim

The base-game side, miscellaneous, bounty, dungeon-miscellaneous, and tutorial inventory passes now cover the source-listed objective-bearing rows. The remaining activity/favor rows with no displayed objective should not become standalone objective rows in this pass; their relationship, marriage, training, investment, or property implications belong in later NPC/property/checklist passes. The only duplicate objective-name cleanup needed here is `Delayed Burial`.

## Routing Relevance

This review prevents route double-counting before the project moves to DLC inventory. It preserves the canonical Dark Brotherhood row for `Delayed Burial`, records its `Sideways` caveat there, keeps the side-quest source-list row only as an excluded duplicate cross-reference, and leaves activity-only favors for later relationship/checklist research instead of inflating the objective database with generic repeatable activities.

## Evidence Summary

UESP's Side Quests page says side quests generally count toward `Sideways`, but explicitly calls out unusual cases. `Delayed Burial` is listed on that page and counts toward the achievement, while otherwise being categorized as a Dark Brotherhood quest with Dark Brotherhood journal knotwork. The objective database already had a Dark Brotherhood row for `Delayed Burial`, so that row remains canonical and the later side-quest inventory row is retained only as an excluded source-list cross-reference.

The same Sideways caveat list says `The Affairs of Hagravens` counts toward `Sideways` despite being treated as a miscellaneous quest and not appearing on the Side Quests page. That row is represented once as a dungeon miscellaneous objective with Sideways caveat citations.

UESP's Miscellaneous Quests page states that favors additionally include certain activities for which no information is displayed in the journal. The prior hold/city passes intentionally did not enter no-objective activity rows such as chopping wood, mining ore, gathering wheat, beggar gifts, drunk gifts, or generic brawls as standalone route objectives. Those activity rows can still matter for NPC relationship, spouse, training, investment, or property eligibility, so their route treatment is deferred to later relationship/property/checklist passes rather than being excluded from the project globally.

## Confidence and Open Questions

Confidence is high for duplicate handling and broad inventory reconciliation. Later passes still need to validate platform-specific trophy behavior, relationship effects, marriage/training/investment/property dependencies, and whether any checklist explicitly tracks an activity-only favor.
