# Source Note: Hero of the People and Miscellaneous Objective Caveats

Status: needs review.

Source note ID: SN-000022

## Claim

UESP identifies `Hero of the People` as a Bronze/30-point achievement for completing 50 miscellaneous objectives. It also notes that the game counts objectives rather than quests, counts objectives outside the Miscellaneous Quests page, can count repeated completion of the same exact objective, and has global miscellaneous quest display and radiant availability bugs.

## Routing Relevance

The PS4 route must preserve trophies, but this project should not depend on exploit-only repeated objective updates. This note supports a parent trophy-tracking row and flags miscellaneous/favor objective rows as potential contributors to `Hero of the People`.

## Evidence Summary

UESP states that `Hero of the People` is obtained by completing 50 miscellaneous objectives. It says objective count, not quest count, is what matters, and that all completed miscellaneous objectives can count even when they are not part of the Miscellaneous Quests page. It also documents that miscellaneous quests may disappear from the active quest list while remaining active, and that some radiant quests can become unavailable if not received on the first visit to a location.

## Confidence and Open Questions

Confidence is high for the trophy requirement and broad count behavior. Exact PS4 Anniversary Edition timing, any platform-specific bug behavior, and which radiant favor rows need first-visit mitigation require later trophy and bug validation.
