# SN-000210 - Solstheim Explorer Trophy Closeout

Status: researched.

Source note ID: SN-000210

## Claim

`Solstheim Explorer` is complete when the route has discovered 30 locations on Solstheim. The existing Dragonborn route already visits more than 30 Solstheim map locations before the final `Lost Knowledge` return, so TB-044 only needs a final counter-verification checkpoint rather than a new geography insertion.

## Routing Relevance

The trophy is a counter objective, not a quest with a turn-in. The route should not ask the player to wander for generic discoveries after the Dragonborn spine; it should name a concrete minimum list already covered by the guide and have the player verify missing map markers before leaving Solstheim.

The checkpoint names the 30-location minimum list, tells the player to revisit any missing map marker from that list before leaving Solstheim, and closes the trophy/counter once the list is satisfied.
