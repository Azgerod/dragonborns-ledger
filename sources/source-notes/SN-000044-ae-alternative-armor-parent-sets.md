# Source Note: AE Alternative Armor Parent Sets

Status: needs review.

Source note ID: SN-000044

## Claim

The AE Creation Club bundle includes fifteen Alternative Armors packages that need parent-set coverage before individual armor-piece, recipe, and acquisition rows are expanded.

## Routing Relevance

The specification requires all AE items and rewards while preserving a gradual difficulty curve. Alternative Armor rows should exist now as source-list parent sets, but exact armor-piece members, crafting recipes, smithing perk needs, quest starts, and power-curve timing belong to later item, crafting, and route passes.
