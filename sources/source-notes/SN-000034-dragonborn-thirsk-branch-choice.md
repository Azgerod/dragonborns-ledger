# Source Note: Dragonborn Thirsk Branch Choice

Status: needs review.

Source note ID: SN-000034

## Claim

`The Chief of Thirsk Hall` and `Retaking Thirsk` are mutually exclusive Dragonborn Thirsk outcomes. The choice determines whether the Rieklings or Nords occupy Thirsk Mead Hall, and it affects availability of related favor objectives.

## Routing Relevance

The guide's branch policy requires a hard-save branch for substantial mutually exclusive content. Thirsk has exclusive quest content and follow-on favor availability, but the default main-route side has not been chosen yet.

## Evidence Summary

UESP's Riekling-side page states that agreeing to help Bujold instead fails `The Chief of Thirsk Hall` and starts `Retaking Thirsk`; its notes also state that only one of the two quests can be completed because the Riekling-side quest requires killing the Nord-side quest giver. UESP's Nord-side page warns that some camp favor content can become unavailable once `Retaking Thirsk` is started and records post-retaking favor availability.

## Confidence and Open Questions

Confidence is high that this is a branch-worthy mutually exclusive choice. Later branch planning must choose the canonical main-route side, identify exactly which favor quests are exclusive to each state, and decide how much branch-only favor content belongs in the hard-save branch.
