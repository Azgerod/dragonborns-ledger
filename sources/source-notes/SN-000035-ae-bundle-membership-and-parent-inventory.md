# Source Note: AE Bundle Membership and Parent Creation Inventory

Status: needs review.

Source note ID: SN-000035

## Claim

Skyrim Anniversary Edition / Anniversary Upgrade scope for this project consists of the official Creation Club bundle included with Anniversary Edition: 74 Creations. These package-level rows are parent inventory records only; detailed quest, item, spell, property, pet, mount, ingredient, location, conflict, and bug rows still need follow-up passes.

## Routing Relevance

The guide is limited to official AE Creation Club bundle content and must exclude later Verified Creator Program or other Creations outside the AE entitlement. A source-backed parent index prevents later AE work from drifting into non-AE content, and it gives each detailed child objective a package parent.

## Evidence Summary

Bethesda support states that Anniversary Edition includes Skyrim Special Edition and 74 Creations. UESP's Creation Club page also states that all 74 Creations are included in Anniversary Edition and distinguishes retired Creation Club content from the later Verified Creator Program, which matters because the project excludes non-AE Creations and third-party content.

UESP's Creation Club table lists the 74 package names and gives package categories plus many start or acquisition hints. The First Time Players page and Creation Club Quests page are useful cross-checks for follow-up work because they organize Creation content by discovery location and quest inventory. A few package-table rows do not expose a complete start parenthetical, so the parent index uses the relevant individual UESP page for Expanded Crossbow Pack, Bones for a Crow, Double-Edged, and A Dying Wish.

## Confidence and Open Questions

Confidence is high that the parent package set is the correct official AE bundle scope. Confidence is medium for using package-table start hints as route-ready triggers; later per-Creation passes must validate exact start conditions, level gates, quest conflicts, bug risks, cell-entry locks, unique rewards, and PS4 trophy-safety implications before route placement.
