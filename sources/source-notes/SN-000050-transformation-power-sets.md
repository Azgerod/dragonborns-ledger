## Claim

Werewolf, Vampire Lord, and vampirism transformation or state systems need source-list objective coverage because the specification requires transformations, all perks, trophy preservation, and branch-safe handling of faction choices.

## Routing Relevance

The canonical main route joins the Companions and Dawnguard, but the guide still needs to account for Beast Form, werewolf totem powers, Vampire Lord access, vampirism state changes, and the all-perks requirement. This pass records those systems without deciding final character state, cure timing, faction branch route, or perk-grind route.
