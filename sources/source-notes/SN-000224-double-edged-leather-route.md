# Double-Edged And Leather Scout Route

Status: researched.

Source note ID: SN-000224

## Claim

`Double-Edged` should be routed in the Haafingar caves loop that already opens the Dragon Bridge, Cliffside Retreat, Lost Echo Cave, and Solitude support corridor. The main route reads and takes `Guard's Dossier: Ehlhiel` and `Zaharia's Note` at Cliffside Retreat, makes `HARD SAVE: HS-DOUBLE-EDGED`, saves Ehlhiel by reading and taking `Note to Ehlhiel` in the Temple of the Divines, clears Lost Echo Cave, defeats Zaharia, and preserves the full enchanted Leather Scout armor set.

## Routing Relevance

The quest page identifies Cliffside Retreat and Lost Echo Cave as the route locations, `Zaharia's Note` as the start document, `Note to Ehlhiel` as the optional save-Ehlhiel intervention, and the full enchanted Leather Scout set as the reward. The Creation page confirms that `Double-Edged`, Ehlhiel, Zaharia, the four book/document titles, and the four Leather Scout armor pieces belong to `Alternative Armors - Leather`.

The existing guide already routed Cliffside Retreat and Lost Echo Cave only as broad Haafingar sweep entries. This pass replaces that shorthand with explicit objective-level instructions, keeps the local skill book closed for the later Scholar's Insight reading window, and records the Lost Echo ceremonial-brazier bug so the player can recover before committing deep into the cave.

## Evidence Summary

`Double-Edged` can be added by asking an innkeeper for work or by finding the note directly, but the route uses direct discovery because the current Haafingar sweep already passes Cliffside Retreat. The quest starts by reading `Zaharia's Note`, which sits at Cliffside Retreat with `Guard's Dossier: Ehlhiel`.

The quest has an irreversible choice. If the player takes `Note to Ehlhiel` from the Temple of the Divines before going to Lost Echo Cave, Zaharia is the hostile agent at the cave. If the player does not take that note, Ehlhiel is the hostile agent. The main route saves Ehlhiel because it closes the source-confirmed `Note to Ehlhiel` document route and still yields the Leather Scout reward set from Zaharia.

Lost Echo Cave contains the related `2920, Morning Star, v1` skill book and a hidden-door mechanic that requires activating the ceremonial brazier with a glowing mushroom. The current guide keeps the skill book closed for the later Scholar's Insight reading window and includes the source-listed hidden-door bug recovery.

The Leather Scout reward is a four-piece armor set: Leather Scout Armor, Leather Scout Boots, Leather Scout Gauntlets, and Leather Scout Helmet. The armor page records that the set lacks a shield and that unenchanted pieces can also be crafted and appear in random loot, but the deterministic route pickup is Zaharia's enchanted set during `Double-Edged`.

`Ehlhiel's Journal` remains unresolved. The checked book page has no location field, and the checked Ehlhiel NPC page does not list the journal in his inventory. The guide therefore does not ask the player to kill Ehlhiel or look for speculative loot.

## Confidence and Open Questions

Confidence is high for the quest start, the save-Ehlhiel path, the Temple of the Divines intervention, the Lost Echo Cave route, the hostile Zaharia encounter, the Leather Scout set reward, and the local bug warning.

The retained open question is `Ehlhiel's Journal`: current UESP pages confirm the document's existence and Creation membership but not a deterministic acquisition source.
