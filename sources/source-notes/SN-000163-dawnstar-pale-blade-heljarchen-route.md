Status: route-writing source note for TB-035-MR-033.

## Scope

This note supports the v1 guide section `Dawnstar, Pale Blade, And Heljarchen`. The pass expands the old scaffold into an executable Pale/Dawnstar route: Kharjo target protection before Frostmere, Dawnstar help objectives, `Unholy Vigil`, Saturalia camp purchases, Yngvild, High Gate Ruins, Frostmere Crypt, the Pale giant camps, Treasure Map VI and cache, `Kill the Giant`, Thane of the Pale, Gregor, Heljarchen Hall purchase, and the Heljarchen foundation.

## Route Decisions

The section begins by recording Kharjo's `Amulet of the Moon` target before Frostmere Crypt. Frostmere is a possible Kharjo target and the project constraint table records the source-backed prior-visit risk for Frostmere, Broken Oar Grotto, and Cracked Tusk Keep. The guide therefore waits/rests for Ahkari's caravan outside Dawnstar, accepts the actual target, and does not ask the player to reroll it. If the target is Frostmere, the guide resolves it during the Frostmere clear; otherwise the target remains recorded for its own later location route.

Leigelf's ore sale and Karl's drunk favor are pulled into this pass because the player is already in Dawnstar, both count toward Pale help, and neither has a route constraint. Beitild's ore sale was already completed before the Dark Brotherhood contract, and Rustleif/Aeri were already completed in prior Dawnstar passes, so this section has enough Pale help to support thaneship after Skald's giant bounty.

`Unholy Vigil` is routed now because it starts and resolves entirely across the Hall of the Vigilant, Dawnstar, Windward Ruins, and Quicksilver Mine. That is not a theme bucket; it is a same-region quest chain whose start, clues, armor sets, documents, and crafting unlock are already adjacent to the current Pale route. The guide reads `Letter to Keeper Carcette`, `Mysterious Note`, `Azarain's Journal`, `Miner's Note`, `Notes on Dissection`, `Galur Rithari's Papers`, and `Fenrik's Journal`, and it deliberately kills Harald before quest completion so `Miner's Note` can be looted and read before the bug-prone post-cultist state. `The Aetherium Wars` at the destroyed Hall remains closed because `Lost to the Ages` belongs with Arkngthamz/Aetherium routing, has multiple available copies, and starting it here would leave a long dormant quest without route benefit.

Saturalia is routed now because Agrane's camp is immediately north of Windward Ruins. The guide speaks to Agrane, buys the four Saturalia outfit members and the Reindeer Bill of Sale, and marks the Reindeer mount while keeping Shadowmere as the active route mount. This is a funded late-route purchase, not an early hidden economy assumption.

Yngvild is routed now rather than held for a later Winterhold or Thieves bucket. It is on the Dawnstar/Winterhold coast, is source-listed clearable, contains the Yngvild Stone of Barenziah, all four Arondil journals, fixed Necromantic Grimoire apparel, and the fixed `Conjure Haunting Spirit` tome. The guide updates the selected source for `Conjure Haunting Spirit` from College vendor stock to the fixed Yngvild tome. `Toying With The Dead` remains unfinished only because the turn-in is in the Ragged Flagon, not because the Yngvild work is being deferred. If Captain Wayfinder's active `Salty Sea-Dogs` target is Yngvild, the guide completes it here; otherwise it leaves Wayfinder's actual target recorded.

High Gate Ruins is routed now because the player is in the Pale and the route has deliberately held College radiants that can send the player to High Gate after Vokun is already dead. Clearing High Gate before accepting those radiants avoids mixing a fixed side quest with later random-target systems. `A Scroll For Anska` is kept as a complete dungeon package: Anska start, lever solution, Vokun, Staff of Fireballs, Storm Call word, Sealed Scroll, reward tome, and clear state. `A Hypothetical Treachery` remains closed because the selected skill-book source is elsewhere and reading it now would violate the Scholar's Insight skill-book policy.

Frostmere Crypt is routed only after level 27+ and after Kharjo's Amulet target is recorded. The project does not treat Frostmere entry as a confirmed Pale Blade cell-entry lock, but the reward itself is held for the level-27 best useful version and Frostmere has a separate Kharjo target risk. The guide approaches from the west road because UESP records the north-approach Eisa trigger bug. It keeps the quest/dungeon chain intact: Eisa scene, Kyr/Eisa/Ra'jirr documents, Pale Lady kill, preserved Pale Blade, Ice Form word, and clear state. `The Red Kitchen Reader` remains closed even though Frostmere is the selected source because the project skill-book policy holds reads for Scholar's Insight; this is a concrete skill-book timing exception, not a theme deferral.

All four Pale giant camps are routed now. Skald's bounty can target Blizzard Rest, Red Road Pass, Stonehill Bluff, or Tumble Arch Pass, and the player is now strong enough and geographically positioned for the camp loop. Clearing all four camps removes a later Pale cleanup burden, while the guide still tells the player to make sure the camp with Skald's active marker gets the required bounty kill. Treasure Map VI is pulled into the Stonehill segment because the map source is immediately west of Stonehill Bluff. The cache is also routed now after the map is acquired because Korvanjund's exterior cache is near the same southern Pale/Heljarchen corridor and does not require entering the Civil War-locked ruin.

Pale thaneship, Gregor, and Heljarchen Hall are completed after Skald's giant bounty because `Waking Nightmare` was already completed, the route has enough Pale help objectives, and the purchase cost is plausible at this late route point after many city/dungeon sections. The guide builds only the Heljarchen foundation now. Full Heljarchen wings, Gregor's steward assignment, bard, carriage driver, stable horse, livestock, and grain mill remain with the later Hearthfire construction/service pass because they depend on Main Hall/service state and the project default wing/service plan.

The route does not start or clear Fort Dunstad, Tower of Mzark, Korvanjund interior, Yngol Barrow, Nightcaller leftovers, or nearby duplicate skill books in this pass. Each hold has a concrete reason: Civil War/quest-locked state, Blackreach/main-quest state, the Coral Claw/Yngol package, already completed Vaermina routing, or skill-book selected-source/read timing.
