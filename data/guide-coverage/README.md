# Guide Coverage Tracking

This directory contains internal QA artifacts for the final guide drafts.

These files are not player-facing guide text. They map polished guide cues and MR sections back to objective IDs, checklist IDs, coverage status, staged/completed state, and unresolved row notes.

Use `main-guide-v1-coverage.csv` while expanding `drafts/final-guide/main-guide-v1.md`. Keep database mechanics here instead of in the player-facing guide body.
