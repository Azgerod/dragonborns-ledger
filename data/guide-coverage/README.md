# Guide Coverage Tracking

This directory contains internal QA artifacts for the final guide drafts.

These files are not player-facing guide text. They map polished guide cues and MR sections back to objective IDs, checklist IDs, coverage status, staged/completed state, and unresolved row notes.

Use `main-guide-v1-coverage.csv` while expanding `drafts/final-guide/main-guide-v1.md`. Keep database mechanics here instead of in the player-facing guide body.

`main-guide-v1-objective-id-audit.csv` is generated by `tools/audit_main_guide_objective_ids.py` for TB-035-COV-001. It records whether each `data/objectives/objectives.csv` row is already represented in the internal guide coverage ledger, appears by literal ID or name in `main-guide-v1.md`, or needs a targeted guide/coverage repair.

`main-guide-v1-checklist-id-audit.csv` is generated by `tools/audit_main_guide_checklist_ids.py` for TB-035-COV-002. It records whether each `data/checklist-mapping/coverage-matrix.csv` row is represented by checklist-specific internal coverage, mapped objective coverage, literal guide IDs, or a mechanical checklist-entry match, and routes unresolved mapping buckets to the focused follow-up audits.

`main-guide-v1-branch-audit.csv` is generated by `tools/audit_main_guide_branch_coverage.py` for TB-035-COV-003. It checks every Branch-route prototype checklist row and every `branch_route` objective row against the guide, branch prototype drafts, and internal coverage ledger, including explicit route-resolution rows and branch rows resolved by main-continuity timing.

`main-guide-v1-option-default-audit.csv` is generated by `tools/audit_main_guide_option_defaults.py` for TB-035-COV-004. It checks every Option-list note checklist row against the guide's route defaults, explicit option-set presentation, relationship option support table, and internal coverage ledger.

`main-guide-v1-exclusion-audit.csv` is generated by `tools/audit_main_guide_exclusions.py` for TB-035-COV-005. It checks every Explicit exclusion checklist row against the guide, source notes, mapped objective coverage, and exact checklist coverage to confirm a named reason and scope boundary.

`main-guide-v1-appendix-audit.csv` is generated by `tools/audit_main_guide_appendix_rows.py` for TB-035-COV-006. It checks every previous Appendix-only checklist row against the self-contained guide and internal coverage ledger, including route-reference entries and merchant service-reference entries promoted into `main-guide-v1.md`.

`main-guide-v1-location-audit.csv` is generated by `tools/audit_main_guide_locations.py` for TB-035-COV-007. It checks every location objective and checklist location row against the guide, internal coverage ledger, location catalog, and geography support tables for discover, enter, clear, avoid, secondary-marker, route-resolution, exclusion, and counter treatment.

`main-guide-v1-book-document-audit.csv` is generated by `tools/audit_main_guide_books_documents.py` for TB-035-COV-008. It checks every book/document-related objective and every Books, Spells, and Dragon Shouts checklist row against the guide, internal coverage ledger, book support tables, progression source selections, and pickup, read, learn, storage, hold, duplicate, exclusion, branch, and route-resolution treatment.

`main-guide-v1-collectible-audit.csv` is generated by `tools/audit_main_guide_collectibles.py` for TB-035-COV-009. It checks finite collectible objectives, Collectible Items checklist rows, relevant Unique Gear rows, item/member support tables, and internal coverage rows for item-by-item route timing, pickup, use/turn-in, storage, hold, exclusion, branch, and route-resolution treatment.

`main-guide-v1-crafting-progression-audit.csv` is generated by `tools/audit_main_guide_crafting_progression.py` for TB-035-COV-010. It checks crafting/progression objectives, skill/perk rows, enchantment-learning rows, alchemy ingredient-effect rows, merchant investment rows, practical crafting systems, level-gate/grind rows, and related checklist rows for named learn, discover, craft, invest, skill, perk, storage, hold, exclusion, branch, and route-resolution treatment.

`main-guide-v1-radiant-counter-audit.csv` is generated by `tools/audit_main_guide_radiant_counters.py` for TB-035-COV-011. It checks radiant objectives, trophy/counter objectives, Fishing species and special catches, work-action rows, and mapped checklist rows for target, assignment, counter, boundary, trophy, Fishing, work-action, no-reroll, branch, exclusion, and route-resolution treatment.
