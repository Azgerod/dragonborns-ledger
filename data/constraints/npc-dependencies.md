# NPC Dependencies

Status: TB-021 reviewed.

Scope: this is a constraint table, not route prose. It records NPCs, services, and role assignments that must remain alive, accessible, non-hostile, or in a valid quest state for later route construction. It does not choose spouse, children, stewards, followers, farmhands, home base, exact trainer use, or exact favor targets; those recommendations remain later writer/default work.
