# Bug-Prone Quests

Status: TB-021 reviewed.

Scope: this table records source-backed bug risks that need order rules, hard saves, verification checkpoints, or explicit no-route treatment for an official PS4 Anniversary Edition route. It does not list every UESP bug note; PC-console-only fixes, Switch/PSVR-only bugs, cosmetic bugs, and Unofficial Patch-only routing are separated from official no-console constraints.
