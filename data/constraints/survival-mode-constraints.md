# Survival Mode Constraints

Status: TB-021 reviewed; TB-021B geography support available.

Scope: this is a constraint table, not route prose. It records Survival Mode mechanics and logistics that must shape later route skeletons: hunger, fatigue, cold, carry weight, bed access, food, transport, storage, and regional sequencing. TB-031D has selected route-affecting defaults in `data/route-planning/route-default-decisions.md`; exact route order, crop choices, stock quantities, and validation warnings remain downstream decisions.

## Constraint Classes

| Class | Meaning |
| --- | --- |
| Global rule | Applies throughout the main route once Survival Mode is active. |
| Infrastructure | Unlock or service that changes how later route blocks can be planned. |
| Regional risk | Area or location class that should be grouped and prepared for before routing. |
| Route recommendation | Not a hard rule by itself, but should be considered when the writer chooses defaults. |
| Handoff | Needs a later route, property, progression, or checklist pass to choose exact implementation. |
