# data/objectives

Objective database materials belong here.

This layer should eventually hold the objective schema, templates, and working objective database before any route skeleton tries to place objectives.

Start with `schema.md`, then use `taxonomy.md` to decide what kinds of rows should exist. Use `objectives.template.csv` as the header source for `objectives.csv`.

Current reconciliation files:

* `ae-creation-manifest.md` maps Anniversary Edition package parent rows to child coverage.
* `unique-item-reconciliation.md` records artifact, unique-item, and leveled-reward boundary decisions.
* `tb-007-reconciliation.md` summarizes collectible, book, reward, property, relationship, and aggregate-member coverage.
* `aggregate-reconciliation.md` closes remaining broad parent/set-row handling before the location and skill-system passes.
