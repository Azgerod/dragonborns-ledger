# Task Board

This board stages the project from structured data through final QA. It is a planning artifact only; rows that require gameplay facts are marked as blocked until a task explicitly starts gameplay research.

Status key:

* Done: deliverable exists for the current project stage.
* In progress: umbrella or staged work has started but child deliverables remain.
* Ready: unblocked and suitable as the next reviewable task.
* Not started: planned, but should wait for dependencies.
* Blocked: requires gameplay research, checklist input, or a prior route artifact.
