# docs

Project-level instructions, requirements, source standards, task planning, and decisions live here.

Read `guide-specification.md` before any project work. Keep durable process decisions in `decisions-log.md` and avoid placing route content in this directory.

| File | Purpose |
| --- | --- |
| `guide-specification.md` | Canonical project requirements. |
| `development-plan.md` | Extracted development sequence. |
| `requirements-index.md` | Map of requirement-bearing documents. |
| `source-standards.md` | Source priority and citation rules. |
| `decisions-log.md` | User-resolved decisions and unresolved defaults. |
| `task-board.md` | Coordination and consistency notes. |
| `session-handoff.md` | Current restart point for a new session. |
